# Programming and Scripting - Weekly Tasks

## Overview
This repository contains a collection of Weekly Tasks completed as part of the Programming and Scripting module, delievered by [ATU](https://www.atu.ie/)

The purpose of this repository is to demonstrate the development of Python programming skills over time, with each task focusing on different concepts and techniques.

## Purpose of the Repository
This repository serves to:
- Track progress throughout the module on a week-by-week basis.
- Showcase practical programming and scripting skills.
- Demonstrate understanding of core Python concepts through continuous assessments.

## Repository Structure
- `account.py` – Read an account number and output the last 4 digits
- `bank.py` – Print out sum of two amounts (cents) into final sum (Euros)
- `collatz.py` – Input of integer outputs successive numbers through calculations until it becomes 1
- `es.py` – Reads in a text file and outputs the number of e's it contains
- `plottask.py` – Histogram of a normal distribution of a 1000 values
- `squareroot.py` – Takes a floating-point number as input and outputs its square root
- `weekday.py` – Outputs whether or not today is a weekday
